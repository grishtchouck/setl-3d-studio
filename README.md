# Сэтл · 3D-планировка студии (прототип)

Прототип просмотра будущей квартиры в 3D для карточки квартиры на setlgroup.ru.
Цель — проверить гипотезу: 3D-план с переключателем «как сдаётся / с мебелью» повышает конверсию в заявку
и помогает продавать пакет меблировки.

## Что внутри

- `index.html` — готовая страница: three.js-вьюер с моделью, встроенной в файл (glTF в base64, ~170 КБ).
- `blender/build_studio.py` — скрипт для Blender 5.x: строит студию по координатам и выгружает `studio.glb`.

## Как устроено

```
координаты планировки → Blender (build_studio.py) → studio.glb → вьюер (index.html)
```

Объекты с префиксом `B_` — база (стены, окна, двери, сантехника), `F_` — пакет меблировки.
Вьюер показывает или скрывает `F_*` по переключателю, а при наведении подписывает предметы по составу пакета.

## Обновить модель

1. Запустить `blender/build_studio.py` в Blender (через MCP или Scripting).
2. Скрипт сохранит `~/Desktop/setl-studio/studio.glb`.
3. Встроить его в `index.html` вместо текущей base64-строки `GLB_B64`.

## Ограничения прототипа

- Координаты сняты с картинки планировки вручную (±5 см). Целевой путь — парсинг SVG планировок.
- Свет считается в браузере; для продакшена — запечённый свет из Blender.
- Мебель — упрощённая геометрия; для продажи меблировки заменить на модели реальных позиций.
- Цена, этаж, срок — условные; кнопки заявок никуда не отправляют.
